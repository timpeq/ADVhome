# Archive

Retired project documents, kept readable rather than deleted. Nothing here is
maintained. Files are named `YYYY-MM-DD-name.md`, dated the day they were
retired, so they sort in the order they were replaced. Each opens with a note
saying what it was and what replaced it, and `git log --follow <file>` shows its
history from before the move.

- [2026-09-12-roadmap.md](2026-09-12-roadmap.md): the phase-based roadmap used
  from 2026-09-06 to 2026-09-11, replaced by the numbered task list in
  [TODO.md](../../TODO.md).
